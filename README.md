# Ironman Hilt Guide

An Ironman-first Combat Achievement guide to **Ghommal’s hilt 2**. Choose a Solo or Group route, check your gear and requirements, and follow tasks toward the Medium reward at 169 points. The guide stores progress on your computer.

Once listed, search for **Ironman Hilt Guide** in RuneLite’s Plugin Hub and select **Install**. Open the **H** sidebar to get started.
